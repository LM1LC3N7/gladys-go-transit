# Third-party notices

## Data

The departures, delays, platforms, service alerts and stop list come from the GO API of Metrolinx
(`api.openmetrolinx.com`), called at run time with the user's own key. No data is shipped with the
integration.

Contains information licensed under the Open Government Licence – Ontario – Metrolinx:
https://assets.metrolinx.com/image/upload/v1663237565/Documents/Metrolinx/Open-Government-Licence-Ontario-Metrolinx.pdf

This integration is not affiliated with, nor endorsed by, Metrolinx. "GO Transit" is a name of
Metrolinx, used only to say which service the integration reads.

## Code

No third-party code is copied or ported. The only runtime dependency is
`@gladysassistant/integration-sdk` (Apache-2.0), installed from npm.
